# BRASA Burger Club — Creative Bold (versão 2)

Projeto de portfólio para uma **hamburgueria fictícia** com visual cream/orange/forest green, hero editorial, hamburguer gigante, cardápio filtrável, seleção de produtos, combo e carrinho funcional em JavaScript.

## Como abrir

1. Extraia todo o conteúdo do ZIP.
2. Abra `index.html` em um navegador.
3. As imagens da galeria e dos produtos carregam da internet. A imagem principal (`assets/brasa-hero.webp`) está incluída no arquivo, para o hero não depender de conexão.

Não é necessário instalar Node, bibliotecas ou extensões.

## Como publicar

Envie `index.html`, `styles.css`, `script.js` e toda a pasta `assets/` para seu repositório. Depois, configure uma hospedagem estática (Cloudflare Pages, por exemplo). O projeto não tem etapa de compilação.

## Funcionamento

- Botões e navegação levam a seções reais.
- Filtros exibem os produtos correspondentes.
- Cada item adicionado atualiza o carrinho e o contador flutuante.
- Controles + e − alteram quantidades.
- O botão de combo adiciona o combo ao carrinho.
- O botão de gerar pedido cria um texto copiável; não transmite dados a terceiros.

**Atenção:** marca, preços e cardápio são fictícios, e as fotos são ilustrativas. O site não recebe pedidos reais. Ao adaptar para um cliente, substitua fotografias por imagens autorizadas e configure atendimento, endereço, horário e condições reais.
